# Guía de Usuario - CronosFacen

Esta guía explica cómo usar la aplicación y ofrece ejemplos prácticos.

**Requisitos**

1. Base de datos creada en el primer inicio.
2. Permisos de escritura en la carpeta de datos de usuario.

**Primer Inicio**

1. Abre la aplicación.
2. Si tienes PIN configurado, ingrésalo para continuar.
3. Verifica que el tema y las pestañas visibles sean las correctas.

**Navegación Rápida**

1. El menú superior contiene accesos directos a las pestañas principales.
2. El botón de menú muestra u oculta el panel lateral.
3. El panel lateral contiene accesos a los administradores de datos.

**Configuraciones**

La pestaña “Configuraciones” permite

1. Cambiar el tema.
2. Configurar o quitar PIN.
3. Definir pestañas visibles.
4. Configurar backups de la base de datos.

**Backups**

1. Selecciona la carpeta de backups.
2. Define cuántos días retener y cuántos backups recientes conservar.
3. Guarda la configuración.
4. Usa “Crear backup ahora” para generar un backup inmediato.
5. Al cerrar la app se genera un backup automático.

**Ejemplo: Configurar backups**

1. Ve a “Configuraciones”.
2. Selecciona la carpeta `C:\Backups\cronos` o `/home/usuario/backups/cronos`.
3. Retención: `30` días, Mantener últimos: `5`.
4. Pulsa “Guardar Backup”.

**Pestaña Actividades**

1. Selecciona un estudiante.
2. Elige carrera, asignatura y tipo de actividad si deseas filtrar.
3. Verás tarjetas con fechas, estado y duración.
4. Usa clic derecho en una actividad para cambiar su estado.

**Ejemplo: Filtrar por tipo de actividad**

1. Abre “Actividades”.
2. Selecciona un estudiante.
3. En “Tipo de Actividades”, elige “Evaluación Parcial (AP) - Alta”.
4. Se muestran solo las actividades de ese tipo.

**Pestaña Alertas**

1. Filtra por carrera, asignatura, tipo y rango.
2. Pulsa “Aplicar Filtros”.
3. Usa “Limpiar” para volver a ver todo.
4. La configuración de filtros se recuerda automáticamente.

**Ejemplo: Ver vencidas**

1. En “Alertas”, selecciona rango “Vencidas”.
2. Pulsa “Aplicar Filtros”.
3. Revisa la lista con estado “Vencida”.

**Pestaña Calendario**

1. Muestra eventos y actividades en un calendario.
2. Usa filtros para ver solo lo que te interesa.
3. Puedes exportar reportes desde el panel de calendario.

**Administración de Datos**

Usa el panel lateral para gestionar:

1. Carreras.
2. Estudiantes.
3. Asignaturas.
4. Ejes temáticos.
5. Tipos de actividad.
6. Actividades.
7. Eventos de calendario.

**Ejemplo: Crear una actividad**

1. Ve a “Administrar Actividades”.
2. Completa título, fechas, tipo y asignatura.
3. Guarda.
4. La actividad aparecerá en la pestaña “Actividades” al filtrar por el estudiante.

**Consejos**

1. Si una pestaña no aparece, revisa “Configuraciones > Pestañas visibles”.
2. Si el panel lateral se oculta en pantallas pequeñas, usa el botón de menú.
3. Usa “Crear backup ahora” antes de cambios masivos.
